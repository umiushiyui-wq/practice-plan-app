# Googleフォーム + スプレッドシート版

この方式では、団員にはGoogleフォームのURLをLINEで送り、管理者はスプレッドシートで集計と練習計画を確認します。

## 1. Googleフォームの質問項目

フォームは回答先をスプレッドシートに接続してください。質問名は下の名前にそろえると、`Code.gs` がそのまま動きます。

| 質問名 | 形式 | 例 |
| --- | --- | --- |
| 名前 | 記述式 | 山田太郎 |
| パート | プルダウン | ふるぼえ / クラリネット / サックス / ホルン / トランペット / トロンボーン / 低音 / パーカス |
| 練習日 | 日付 | 2026/04/12 |
| 出欠 | ラジオボタン | 出席 / 欠席 |
| 参加可能開始 | 時刻 | 18:00 |
| 参加可能終了 | 時刻 | 21:00 |
| 出演できる曲 | チェックボックス | 曲名を選択 |

欠席の場合、参加可能開始・終了は空でもOKです。

## 2. スプレッドシートのシート構成

`Code.gs` をApps Scriptに入れて `初期シート作成` を実行すると、次の管理用シートを作ります。

| シート名 | 役割 |
| --- | --- |
| 設定_奏者 | 全奏者の名簿。未回答者を表示するために使います。 |
| 設定_練習日 | 練習日の一覧。時間表をこの日付順で作ります。 |
| 設定_曲 | 練習計画に使う曲メモ。 |
| 集計_参加可能時間 | 奏者ごとの参加可能時間を緑で表示します。 |
| 練習計画 | 管理者が練習計画を書く表です。 |

## 3. Apps Scriptの入れ方

1. 回答先スプレッドシートを開く
2. `拡張機能` → `Apps Script`
3. `Code.gs` の中身を貼る
4. 保存
5. スプレッドシートを再読み込み
6. メニュー `練習計画` → `初期シート作成`
7. `設定_奏者` と `設定_練習日` を入力
8. メニュー `練習計画` → `参加可能時間表を更新`

## 4. 日付・時間の入力形式

`初期シート作成` を実行すると、`設定_練習日` と `練習計画` の日付・時間列に表示形式が入ります。

| シート | 列 | 入力例 |
| --- | --- | --- |
| 設定_練習日 | 練習日 | 2026/04/12 |
| 設定_練習日 | 開始 | 18:00 |
| 設定_練習日 | 終了 | 21:00 |
| 練習計画 | 練習日 | 2026/04/12 |
| 練習計画 | 開始 | 18:00 |
| 練習計画 | 終了 | 18:30 |
| 練習計画 | 分 | 30 |

## 5. 運用

団員にはGoogleフォームのURLをLINEで送ります。

管理者は回答が集まったら、スプレッドシートで `練習計画` → `参加可能時間表を更新` を押します。横軸は8:00〜22:00で、参加可能なセルが緑になります。緑セルにカーソルを置くと、入力された参加可能時間がノートで見えます。
